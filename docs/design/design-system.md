## 1. デザイン原則（コンセプト → 視覚の翻訳）

1. **稼働一覧が主役** — 余白を多く取り、リアルタイム稼働状況を画面の中心に据える。装飾はそれを邪魔しない。
2. **誠実で落ち着いたトーン** — 煽らない、盛らない。事実（動いている/いない）を静かに見せることが信頼になる。
3. **一般の人に伝わる言葉** — 技術用語を排し（O38）、初見の人が入口で「何のサイトか」を理解できる（O41）。
4. **手仕事の温かみを控えめに** — 温かみのあるペーパー調の地で、量産ではなく丁寧に作っている感触を出す。やりすぎない。
5. **状態色は機能、ブランド色は teal** — up/down/unknown の状態色（緑/琥珀/グレー）はブランドの teal と区別し、誤読を防ぐ。

## 2. カラートークン（Ink & Teal）

| トークン | 値（目安） | 用途 |
|---|---|---|
| `--bg` | `#FAF9F6`（温 off-white / paper） | ページ背景 |
| `--surface` | `#FFFFFF` | カード・パネル面 |
| `--surface-subtle` | `#F3F1EC` | 区切り面・薄い面 |
| `--border` | `#E6E2D9`（温い薄ボーダー） | 境界線 |
| `--ink` | `#1E2722`（深いインク、わずかに暖） | 主テキスト |
| `--ink-muted` | `#5C625D` | 副次テキスト・ラベル |
| `--primary` | `#0E7C72`（落ち着いた teal） | 主ボタン・リンク・強調 |
| `--primary-hover` | `#0B645C` | 主ボタン hover |
| `--primary-subtle` | `#E2F1EF`（teal 薄） | バッジ背景・選択面 |
| `--accent` | `#5EAAA2`（teal 系ライト） | 補助強調（控えめ） |
| `--status-up` | `#2F9E44`（緑） | 稼働中 |
| `--status-down` | `#D97706`（琥珀） | 停止/不達（hard-down は赤 `#DC2626` にエスカレート可） |
| `--status-unknown` | `#9CA3AF`（グレー） | 確認中/不明 |
| `--focus-ring` | `#0E7C72` 50%α | フォーカスリング |

- コントラスト: `--ink` on `--bg` / `--surface` は WCAG AA 以上。`--primary` on white もボタン文字（白 on teal）で AA 確保。
- ダークモード: MVP では省略（余白多めの light のみ）。将来トークンを dark セットで複製。

## 3. タイポグラフィ

- **フォント**: 中立サンセリフ。EN = Inter（or system-ui）、JP = Noto Sans JP。Web フォントは可変・サブセットで軽量化（初回表示軽量 NFR）。
- **スケール**（余白多め、ゆったり行間）:

| 役割 | サイズ目安 | 行間 | ウェイト |
|---|---|---|---|
| display（ヒーロー見出し） | 36–44px | 1.2 | 600 |
| h1 | 28px | 1.3 | 600 |
| h2 | 22px | 1.35 | 600 |
| body | 16px | 1.7 | 400 |
| small / label | 13–14px | 1.5 | 500 |

- 長文（LP コピー / 法務）は body 16px / line-height 1.7 で読みやすさ優先。

## 4. 形・影・余白

- **余白スケール**（4px ベース）: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。セクション間は 48–64、カード内 16–24。
- **角丸**: `--radius-sm` 6px（チップ/入力）、`--radius-md` 10px（カード/ボタン）、`--radius-lg` 14px（モーダル/大パネル）。ミニマルだが角は少し柔らかく（クラフト感）。
- **影**: 最小限。`--shadow-sm`（薄い 1 段）をカードに控えめに。強い影は使わない（ミニマル）。境界は影より `--border` で表現。

## 5. コンポーネント（基本形）

- **Button**: `primary`（teal 塗り + 白文字）/ `secondary`（teal アウトライン）/ `ghost`（地に溶ける）。角丸 md、余白 12×20。
- **StatusCard**: 稼働サービス 1 件。`[状態ドット] サービス名 … 稼働N日 →`。状態ドット = `--status-*` の塗り円（**絵文字は使わない**）。hover で薄く面色、行全体がリンク。
- **StatusBadge / Chip**: 状態ラベル（plain 文言、§6）+ ドット。背景 `--primary-subtle` or 状態薄色。
- **Input / Textarea**: 1px `--border`、focus で `--focus-ring`。問い合わせフォーム用。
- **Header（ナビ）**: ミニマル。左にロゴワードマーク `shipyard`、右に「お問い合わせ」リンク。境界線下 1px。
- **Footer**: 控えめ。法務リンク（プライバシー / 利用規約）、コピーライト、控えめなメイカー文脈（「AI 駆動開発で週1ペースに作っています」）。
- **InfoButton（O41 「これは何？」導線）**: 丸付き「?」+ 軽量モーダル。**ただし LP のヒーローにリード文があるため通常は不要**（§7 参照）。サブページ単体流入時の保険として標準化。
- **EmptyState**: 自作 SVG line-art（teal-tint、テーマ色追従）+ 一言。例: 問い合わせ 0 件の admin、サービス取得不可時。
- **ProgressFeedback（O45）**: 問い合わせ送信時の短い非同期（スパム検証 + スレッド生成）で、素のスピナーでなく「送信内容を確認しています → スレッドを用意しています」の段階文言 + 軽い動き。**嘘進捗・わざと遅延は禁止**。

## 6. ボイス & コピー（O38 準拠）

- **トーン**: 誠実・控えめ・押し付けない。一人称は抑えめ、相手を急かさない。コンサル文面は煽らない（charter §2.2）。
- **技術用語 NG → 言い換え**:

| NG（技術用語） | OK（一般向け） |
|---|---|
| 稼働ステータス / up・down | 動いています / 止まっているかも / 確認中 |
| エンドポイント / API | （表に出さない） |
| デプロイ / ホスティング | 公開しています |
| マイクロサービス | サービス / アプリ |
| キャッシュ / フェッチ | 最新の様子（「〜時点の状況」） |

- **状態ラベル**: up=「動いています」（緑）/ down=「止まっているかも」（琥珀）/ unknown=「確認中」（グレー）。
- **エラーメッセージ方針**: 何が起きたか + どうすればいいかを平易に。技術詳細・DB 内容は出さない（§3.7 SEC-001 PII）。
- **詳細な文言の仕上げ**: 実装後に `/flow:wording`（O42 対話校正 + JA→EN 整合）で人間が声を整える。

## 7. 入口の「これは何？」理解（O41）

- LP ヒーローに**リード文**（例: 「週1ペースで作っている、動いているサービスたち。個人開発のマイクロサービスの今をまとめた場所です。AI 駆動開発のご相談も承ります。」）を置くことで、初見の人が入口で正体を理解できる → **インライン・リードを優先、InfoButton は通常不要**。
- ただし `service-status` / `legal` 等のサブページ単体に流入した場合の保険として、ヘッダのワードマーク横に控えめな「これは何？」リンク（or InfoButton）を置ける設計にしておく。

## 8. アイコン & イラスト戦略（原則 4）

- **UI アイコン**: OSS アイコンセット（例: lucide）。**絵文字は使わない**（環境依存で崩れる）。
- **状態表現**: 塗り円ドット（`--status-*`）。アイコンではなく色 + 形 + plain ラベルの三重で識別（色覚配慮）。
- **ブランドイラスト**: 自作 SVG line-art（teal-tint、テーマ色追従）。モチーフは「船渠/ドック（shipyard）」の軽い line-art をヒーロー装飾・空状態に。やりすぎない（ミニマル）。
- **写実ラスター**: 原則不使用（要キーのエスケープハッチ、本 PJ では不要）。

## 9. レビュー基準（視覚 + コピー、Phase 3 で適用）

- [ ] 階層: 稼働一覧が視覚的主役、余白で呼吸がある
- [ ] 色: 状態色（緑/琥珀/グレー）が teal ブランド色と混同しない、WCAG AA コントラスト
- [ ] トーン: 誠実・控えめ、煽りなし（コンサル CTA 含む）
- [ ] コピー: 技術用語 deny-list ヒットなし（O38）
- [ ] 入口理解: 初見の人がヒーローで正体を言える（O41）
- [ ] 進捗体験: 問い合わせ送信の非同期が段階文言（O45）、嘘進捗なし
- [ ] アイコン: 絵文字なし、状態は色+形+ラベル
- [ ] a11y: フォーカスリング可視、role/text が壊れていない
