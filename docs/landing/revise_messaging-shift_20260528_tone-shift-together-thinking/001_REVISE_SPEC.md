## 1. 変更概要

LP のコアメッセージングを **「AI 駆動開発で速く作る／コンサル承ります」型 (lead-gen 装置)** から **「正解の見えない世界で『共に考え・共に悩む』相談相手として出会う」型 (スタンス開示型)** へ転換する。中央書類 (`docs/concept.md` 冒頭表 / §1 / §1.1 UC#3) は前段セッション (D20260528-001) で更新済。本改修はその LP SPEC 反映。文言・トーン変更のみで、ルート/URL/API/データ層は不変。

## 2. 変更前 vs 変更後

### 2.1 UC 変更

| UC ID | 変更前 (元 SPEC §1) | 変更後 | 理由 |

| UC-L1 | 出力: 「動いているサービスの一覧 + AI 駆動開発のメイカー + 相談できる」が伝わる | 出力: 「動いているサービスの一覧 + AI 駆動開発を週1で回しているメイカー + **『AI 活用の絶対の正解は分からない。正解の見えない世界で共に考える相談相手として手伝いたい』というスタンス** + 共感したら相談できる」が伝わる | concept §1.1 UC#3 と同期 (D20260528-001、wants.md 2026-05-28 起点)。O41 入口理解の解像度を「何ができるか」だけでなく「**どんなスタンスで関わるか**」まで上げる |

## 7. 詳細仕様 (新仕様)

### 7.1 詳細 UC (新仕様)

#### UC-L1: トップで「何のサイトか」「どんなスタンスか」を理解する (concept §1.1 #1/#3/#6, O41 強化)

- **トリガー**: 検索 / SNS / 直リンクで `/` に到達
- **前提**: 認証なし
- **処理**:
  1. ヒーロー (リード文) — 「**動いているサービスを週1ペースで作っている、個人開発のメイカーです。AI 駆動開発を回していますが、それが絶対の正解だとは思いません。AI 活用の正解が見えない時代に、共に考え・共に悩む相談相手として手伝います。**」(暫定文案、`/flow:wording` で仕上げ)
  2. 稼働一覧 (service-status component 埋め込み) — 「いま動いているサービスたち」(design SoT §6 ラベル維持)
  3. 提供価値セクション — 「実装力 (動いているサービス群が裏付け) + 週1ペースの実践実績 + 共に考えるスタンス」の 3 点を 1 セクションで提示
  4. ConsultPitch セクション — 「**『AI 駆動でビジネスを成功させましょう』とは言いません**。1〜2 年後にこのやり方が通用するかは分からないし、AI 活用の絶対の正解は誰にも分かっていないからです。だからこそ、**正解の見えない世界で『共に考え・共に悩む』**ことを大切に、あなたのビジネスの強みを生かしてご一緒したいと思っています。**『これからを共に考えてほしい』と感じたら、お気軽にどうぞ。**」(暫定文案)
  5. CTA — 「ご相談はこちら」(controlled、煽らない、design SoT §6 トーン準拠)
  6. フッタ
- **出力**: 初見でも以下が伝わる:
  - **何のサイトか**: 動いているサービス一覧 + AI 駆動開発の個人メイカー (元 UC-L1 同等)
  - **何ができるか**: 実装力は稼働サービス一覧が裏付け
  - **どんなスタンスで関わるか**: 「絶対の正解」を売らない、共に考える / 共に悩む相談相手として手伝う (O41 強化、本改修の核)
  - **共感したら相談できる**: CTA 導線が控えめに存在
- **例外**: 稼働一覧取得不可 → service-status 側 graceful (EmptyState)

#### UC-L2: スタンスに共感して問い合わせへ進む (concept §1.1 #3→#4)

- **トリガー**: UC-L1 を読み終えた訪問者が ConsultPitch / Hero CTA をクリック
- **処理**: 「ご相談はこちら」CTA → `/contact` (inquiry) へ遷移
- **出力**:
  - inquiry フォームへ遷移
  - CTA テキストは「ご相談はこちら」など煽らない短文 (charter §2.2 / O31 / design SoT §6 維持)
  - **CTA 前後の ConsultPitch コピーで「共に考える」スタンスが暗黙に伝わる** (CTA 本体は短いが、文脈がスタンスを補強)
